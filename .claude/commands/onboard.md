Run, in order:

1. Tier 3 orientation (`protocols/orientation.md`).
2. Domain Boot Camp / induction for the relevant domain — see `/induct` (`protocols/induction.md`).
3. Calibration (`docs/onboarding-calibration.md`): ask how AI-like and how creative human-facing output should be.

This is the ONBOARD mission archetype — heavier than a normal session start. Only run it for genuinely new domains or new operatives, not every session.

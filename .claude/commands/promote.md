---
description: Trigger a promotion review (Rookie/Veteran/Elite/Legend)
---

Follow `protocols/promotion.md`. THE DEMOCRACY OFFICER (or acting auditor) checks:

1. PASS mission count + PASS rate in `experience/operational/`.
2. Feedback ledger — no unresolved CRITICAL/severe corrections.
3. `experience/learned/` entries authored (required for Elite+).
4. Boot Camp graduation events, mentoring record (for higher tiers).

The operative never self-approves. If evidence is incomplete, state which criterion is unmet and stop — do not advance the level anyway.
